# Ishika & Sidhant – Wedding Invite

Everything is ready: song (music/song.mp3), photo (images/couple.jpg), Maps links.

## Publish on GitHub Pages (from Ishika's account)
1. Unzip this folder on a laptop/desktop.
2. Log in at github.com → top-right "+" → New repository.
3. Name: ishika-sidhant · select Public · Create repository.
4. Click "uploading an existing file".
5. Drag in index.html and the images and music folders (not the outer folder) → Commit changes.
6. Settings → Pages → Source: Deploy from a branch → Branch: main, folder: / (root) → Save.
7. Wait 1–2 min, refresh Pages: link = https://USERNAME.github.io/ishika-sidhant/
8. WhatsApp preview: edit index.html (pencil icon), replace YOUR-USERNAME in the og:image line → Commit.
